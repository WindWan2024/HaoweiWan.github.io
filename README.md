# 万浩为设计作品集

这是可直接部署的静态网站，无需安装依赖或运行构建程序。

## 文件

- `index.html`：页面结构与原始矢量画面。
- `style.css`：网站样式和动画。
- `script.js`：导航、交互和视频播放逻辑。
- `assets/images/`：无损压缩图片。
- `assets/videos/`：产品展示和组装视频。

## 在本地打开

用浏览器打开 `index.html`。保持文件夹结构完整，以便加载图片、样式、脚本和视频。

## 部署到 GitHub Pages

1. 创建或打开 GitHub 仓库，将本文件夹**里面的文件和 `assets` 文件夹**上传到仓库根目录。
2. 在仓库的 **Settings → Pages** 中，选择从分支部署，选择 `main` 分支和 `/ (root)`，然后保存。
3. 等待 GitHub Pages 完成部署，访问设置页面显示的网址。

更多说明请参阅 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages)。
